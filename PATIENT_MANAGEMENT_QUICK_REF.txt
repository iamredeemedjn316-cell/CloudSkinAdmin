FEATURE: Complete patient profile management with edit, archive, and delete

================================================================================
QUICK ACCESS
================================================================================

TO EDIT A PATIENT:
  1. Patients page → Find patient row
  2. Click PENCIL ICON (✏️)
  3. Edit modal opens
  4. Update: Name, Phone, Email, DOB, Address
  5. Click "Save Changes"
  → Patient list updates immediately

TO TOGGLE STATUS (Active ↔ Inactive):
  1. Patients page → Find patient row
  2. Click THREE DOTS MENU (⋮)
  3. Select "Toggle Status"
  4. Confirmation modal appears
  5. Click "Toggle Status" (Blue button)
  → Status changes instantly, badge updates

TO ARCHIVE A PATIENT:
  1. Patients page → Find patient row
  2. Click THREE DOTS MENU (⋮)
  3. Select "Archive" (Orange text)
  4. Confirmation modal: "Archive Patient?"
  5. Click "Archive" (Orange button)
  → Patient disappears from list, data preserved

TO DELETE A PATIENT:
  1. Patients page → Find patient row
  2. Click THREE DOTS MENU (⋮)
  3. Select "Delete" (Red text)
  4. Confirmation modal: "Delete Patient?" ⚠️
  5. Click "Delete" (Red button)
  → Patient permanently deleted, cannot recover

================================================================================
ACTION MENU OPTIONS
================================================================================

Action Menu Appears When: Click ⋮ (three dots) on patient row

Options (Top to Bottom):
  1. "Toggle Status" - Gray text
     Changes active ↔ inactive
     Confirmation: Blue modal, 🔄 icon

  2. "Archive" - Orange text (#F97316)
     Soft delete, hides patient
     Confirmation: Orange modal, 📦 icon

  3. "Delete" - Red text (#EF4444)
     Permanent delete, no recovery
     Confirmation: Red modal, ⚠️ icon

================================================================================
STATE MANAGEMENT
================================================================================

Component State Variables:
  • showEditModal: boolean
    → Controls Edit Patient modal visibility
  
  • editingPatient: Patient object
    → Current patient being edited
  
  • patientList: Patient[]
    → Full list of patients (source of truth)
  
  • showConfirmModal: boolean
    → Controls Confirmation modal visibility
  
  • confirmAction: { type, patientId }
    → Tracks which action to confirm (archive/delete/toggle)
  
  • actionMenuOpen: string | null
    → Which patient's action menu is open (by ID)

================================================================================
FILTERING LOGIC
================================================================================

Patients shown in table:
  • NOT archived (archived: false)
  • Match search query (name, phone, email)

Formula:
  filtered = patientList.filter(
    p => !p.archived && (
      p.name.includes(search) ||
      p.phone.includes(search) ||
      p.email.includes(search)
    )
  )

Result: Archived patients automatically hidden from list
